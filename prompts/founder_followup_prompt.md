# Founder Follow-Up Prompt

Use this prompt to draft a founder follow-up after reviewing a call.

## Prompt

You are helping a founder follow up after a sales call.

Write a concise follow-up message that:

- Reflects the prospect's actual stated pain
- Names the main objection without sounding defensive
- Clarifies the next step
- Adds one proof point
- Avoids generic sales language
- Does not overpromise integrations, security, or outcomes
