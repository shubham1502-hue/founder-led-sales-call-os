# Where This Fits in Founder OS

Founder-Led Sales Call OS is the post-call intelligence layer in a broader founder-facing operating system.

## Portfolio architecture

- Pre-call: [ai-gtm-command-center](https://github.com/shubham1502-hue/ai-gtm-command-center)
- Post-call: `founder-led-sales-call-os`
- Weekly revenue diagnosis: [founder-os-revenue-engine](https://github.com/shubham1502-hue/founder-os-revenue-engine)
- Weekly operating review: [founder-weekly-operating-review-agent](https://github.com/shubham1502-hue/founder-weekly-operating-review-agent)
- Investor narrative: [board-pack-investor-update-agent](https://github.com/shubham1502-hue/board-pack-investor-update-agent)
- Umbrella: [founder-os](https://github.com/shubham1502-hue/founder-os)

## What this repo owns

This repo owns the workflow after sales calls happen:

- Ingest call notes
- Extract what prospects said
- Identify repeated objections
- Surface urgency and deal risk
- Create deal rescue actions
- Generate weekly sales learning
- Recommend narrative experiments

## What this repo does not own

This repo should not become:

- An outbound sequencing tool
- A target account research tool
- A cold email generator
- A generic ICP scoring demo
- A replacement for CRM

The core object is the sales conversation. The core output is founder learning.
