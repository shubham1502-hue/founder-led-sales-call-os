# Code of Conduct

## Our standard

This project welcomes useful, respectful contributions from founders, operators, and engineers.

Contributors are expected to:

- Be direct and constructive.
- Respect different levels of technical experience.
- Keep feedback focused on the work.
- Avoid harassment, personal attacks, and discriminatory language.
- Protect private customer, prospect, and company data.

## Unacceptable behavior

Unacceptable behavior includes:

- Sharing private sales call notes or customer data without permission.
- Harassment or personal attacks.
- Spam, self-promotion unrelated to the project, or misleading claims.
- Publishing secrets, credentials, or private API keys.

## Enforcement

Maintainers may remove comments, issues, pull requests, or contributors that violate this code of conduct.
